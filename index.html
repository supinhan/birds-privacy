感谢你游玩《候鸟回归》。我们重视你的隐私。这份政策说明本游戏如何处理你的信息。 本游戏是一款离线运行的 Windows 单机游戏，不需要注册账号，也不需要联网。

1. 适用范围

本政策适用于 Windows 64 位版《候鸟回归》（包括 demo 版本）。 如果你通过 Steam 等平台下载或运行本游戏，平台自身的隐私政策同样适用，请一并阅读。

2. 我们收集哪些信息

本游戏不收集、不上传个人信息。具体来说：

  • 不需要注册账号，不要求联网；
  • 不收集姓名、邮箱、电话号码、住址、位置等个人信息；
  • 不包含广告、第三方统计分析、社交、支付或用户生成内容功能；
  • 不包含聊天、语音或摄像头功能；
  • 不读取你的通讯录、照片、麦克风、摄像头或其他个人文件。

本游戏使用 Unity 引擎构建。Unity 引擎可能在本机生成运行所需的安装标识、会话标识和窗口设置； 这些信息仅保存在你的电脑上，不会由本游戏上传到我们的服务器。

3. 保存在本机的数据

游戏只在本机保存以下内容，用于让你下次继续游玩：

数据用途保存位置是否上传
羽毛、关卡进度、营地升级、教程 / 规则书阅读记录、最高雁群规模 保存游戏进度 Windows 注册表 否
窗口分辨率、画面设置、按键绑定 保存你的显示与操作偏好 Windows 注册表 否
运行日志（Player.log） 排查崩溃或运行问题 本机 AppData 目录 否

具体位置：

  • 游戏进度与设置：
    HKEY_CURRENT_USER\Software\BirdsPrototype\候鸟回归
  • 运行日志：
    %USERPROFILE%\AppData\LocalLow\BirdsPrototype\候鸟回归\Player.log

这些数据不会上传到我们的服务器。你可以随时删除上述注册表项来清除游戏进度； 删除后窗口设置也会一并重置。卸载游戏不一定会自动删除这些数据。

4. 第三方服务

  • 本游戏使用 Unity 引擎（Unity Technologies）构建；
  • 不集成第三方广告、统计分析、支付、社交或推送 SDK；
  • 如果你通过 Steam 等平台购买、下载或运行本游戏，平台可能按照其自身隐私政策收集信息； 这部分处理由平台负责，不属于本游戏。

5. 儿童隐私

本游戏不面向儿童收集个人信息。由于游戏不收集任何个人信息，我们不会主动收集儿童的个人信息。 如果你是未成年人，请在监护人指导下阅读本政策并使用本游戏。

6. 你的权利

由于我们不收集、不上传个人信息，通常不存在需要访问、更正或删除的服务器端数据。 你可以随时删除本机的注册表项来清除游戏进度和设置。如需咨询，可通过下方的联系邮箱联系我们。
